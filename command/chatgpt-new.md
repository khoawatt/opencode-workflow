---
description: Bắt đầu một ChatGPT conversation mới cho repo + branch hiện tại
agent: build
---

Start a fresh ChatGPT conversation for the current repo+branch. Run:

`~/.config/opencode/chatgpt-bridge/bin/chatgpt-review reset`

Then tell the user the next `@chatgpt-review` will use a brand-new ChatGPT
thread for this repo+branch (previous context will not be carried over).
