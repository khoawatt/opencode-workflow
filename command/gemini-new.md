---
description: Bắt đầu một Google Gemini conversation mới cho repo + branch hiện tại
agent: build
---

Start a fresh Gemini conversation for the current repo+branch. Run:

`~/.config/opencode/gemini-bridge/bin/gemini-review reset`

Then tell the user the next `@gemini-review` will use a brand-new Gemini thread
for this repo+branch (previous context will not be carried over).
